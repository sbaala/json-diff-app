## **🎙️ If You Want Voice-Over**

### **Step 1: Record Voice-Over**

```bash
# Option A: GarageBand (built-in)
open -a GarageBand
# → Create Empty Project → Record voice-over → Export as MP3

# Option B: Audacity (free, cross-platform)
brew install audacity
# → Ctrl+R to record → Export as MP3

# Option C: macOS QuickTime
open -a "QuickTime Player"
# → File → New Audio Recording → Record → Save
```

**Tip:** Use scripts from `VOICEOVER_SCRIPTS.md`. Read at natural pace (140–160 wpm).

### **Step 2: Combine Video + Audio**

```bash
# After recording voiceover.mp3:
ffmpeg -i json-diff-30s.mp4 -i voiceover.mp3 \
  -c:v copy -c:a aac -shortest \
  json-diff-30s-narrated.mp4

# Adjust audio volume (if needed):
ffmpeg -i json-diff-30s.mp4 -i voiceover.mp3 \
  -filter_complex "[1]volume=0.8[a]" \
  -map 0:v -map "[a]" \
  -c:v copy -c:a aac -shortest \
  json-diff-30s-narrated.mp4
```

**Result:** `json-diff-30s-narrated.mp4` ready to share.

## **📐 Technical Specs Reference**

### **Recording Settings**

```
Resolution: 1920×1080 (16:9) or 1080×1920 (9:16 vertical)
Frame Rate: 24–30 fps
Codec: H.264 (MP4)
Audio: AAC, 128–192 kbps
```

### **Exporting for Each Platform**

| Platform | Format | Size | Aspect | Duration |
|----------|--------|------|--------|----------|
| Twitter | MP4 | <512MB | 16:9 | 15–30s |
| LinkedIn | MP4 | <10MB | 16:9 or 1:1 | 30–60s |
| TikTok | MP4 | <300MB | 9:16 | <60s |
| Reels | MP4 | <500MB | 1:1 or 9:16 | <90s |
| YouTube | MP4 | <128GB | 16:9 | 60s+ |
| Website | MP4/WebM | <5MB | 16:9 | any |

### **File Conversion Recipes**

```bash
# MP4 → WebM (smaller, web-optimized)
ffmpeg -i input.mp4 -c:v libvpx-vp9 -crf 30 output.webm

# MP4 → GIF (Slack, Discord)
ffmpeg -i input.mp4 -vf "fps=10,scale=1280:-1" output.gif

# Trim to exact time (e.g., 30s)
ffmpeg -i input.mp4 -t 30 -c:v copy -c:a copy output.mp4

# Rotate 90° for vertical
ffmpeg -i input.mp4 -vf "rotate=90" output.mp4

# Add watermark/logo
ffmpeg -i input.mp4 -i logo.png \
  -filter_complex "overlay=10:10" output.mp4
```

## **❓ FAQ**

**Q: Do I need to add captions?**  
A: No, but they significantly boost engagement (especially on silent-by-default platforms like LinkedIn, Twitter). Use auto-captions from the platform.

**Q: Can I customize the HTML?**  
A: Yes! Edit the colors, text, timing directly in the file. Changes take effect immediately.

**Q: Which version should I start with?**  
A: Start with the 30-second horizontal version (`json-diff-30s.html`)—it's the most versatile and takes 2 minutes to record.

**Q: What if I don't have a voiceover?**  
A: That's fine! The text-on-screen version works great for Twitter, TikTok, and LinkedIn. Videos without audio actually perform well on those platforms.

**Q: How do I add music?**  
A: Use the platform's native audio library (TikTok/Reels) or add with ffmpeg:
```bash
ffmpeg -i video.mp4 -i music.mp3 -c:v copy -c:a aac \
  -filter_complex "[0]volume=0.8[v];[1]volume=0.3[a];[v][a]amix" \
  output.mp4
```

**Q: Can I embed these on my website?**  
A: Yes, both the MP4 video and the HTML files work:
```html
<!-- Embed MP4 -->
<video width="100%" controls>
  <source src="json-diff-30s.mp4" type="video/mp4">
</video>

<!-- Or embed the HTML (fullscreen experience) -->
<iframe src="/json-diff-30s.html" width="100%" height="600"></iframe>
```
